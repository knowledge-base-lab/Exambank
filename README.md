# Exam Bank（測試版）

手機優先（iPhone）的考試題庫練習 App。單一 HTML 檔，資料只存在使用者自己瀏覽器的 localStorage，沒有後端、沒有帳號、沒有 API 金鑰。

> **這是獨立的測試版**，只用來在 iPhone 上驗收，不是正式版。

## 功能
- 選擇題、申論題練習與錯題複習
- 題庫 JSON／PDF 匯入、完整備份與還原
- 申論題匯入（先預覽、重複檢查、可復原）與年度／科目／考卷篩選
- 圖片（附圖）支援（圖片包需另外匯入）

## 使用
開啟 `index.html`（或 GitHub Pages 網址）即可使用。

## 資料與隱私
- 此儲存庫只有程式，**不含任何題庫、作答紀錄或圖片包**。
- 題目與作答都存在你自己的瀏覽器裡，換瀏覽器或清除網站資料會消失，請定期使用「備份與還原」。
- 與其他網址（例如 Claude 上的版本）的資料彼此獨立，不會互相寫入。
- 外部連線只有：Google Fonts（字型）與 cdnjs 的 pdf.js 3.11.174（匯入 PDF 時使用）。不會上傳你的資料。
